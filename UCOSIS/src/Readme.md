README - Sistema de calificaciones en Java

1.Qué es este proyecto?

Este proyecto es un sistema de calificaciones para la universidad
catolica de Oriente. La idea basicamente es crear un programa sencillo
que permita registrar estudiantes junto con tres notas, calcular
automaticamente su promedio y mostrar si el estudiante está aprobado
o reprobado.

Lo hicimos para que los profes tengan una alternativa sencilla y basica
para cuando los profesores necesiten pasar las notas de una forma rapida
y consultar sus resultados sin ningun problema.

Aunque el programa en si es sencillo, aplicamos varios de los conceptos
basicos enseñados en clase, como:

Clases y objetos.

Atributos.

Constructores.

Métodos.

Tipos de datos.

Condicionales.

Ciclos.

switch.

ArrayList.

Entrada de datos con Scanner.

Validación de datos.

Uso de return.

Uso de void.


Como estructura general del programa, funciona así:
El archivo principal tiene dos clases
class Estudiante
y
class SistemaCalificaciones

La clase Estudiante representa la informacion que tiene cada estudiante

La clase SistemaCalificaciones contiene lo que es el menu principal y se
encarga de controlar el funcionamiento del programa.


Basicamente:

Estudiante: Representa los datos y las operaciones que se realizan en estudiante

SistemaCalificaciones: Controla el programa y la interaccion con el usuario.
